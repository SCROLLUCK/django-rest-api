# API Django REST

Projeto de uma API simples usando Django com rest_framework

# Desenvolvimento

Para rodar o projeto localmente, siga os seguintes passos:

1. Execute `python3 manage.py makemigrations` para criar as migrações de banco de dados.
2. Execute `python3 manage.py migrate` para aplicar as migrações de banco de dados.
3. Execute `python3 manage.py createsuperuser` para criar um usuário administrador.
4. Execute `python3 manage.py runserver` para rodar o servidor de desenvolvimento.
